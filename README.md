## Sobre a VORA

**VORA** é uma startup angolana de desenvolvimento de software. Nosso nome significa **"voraz"** – porque somos ágeis, intensos e focados em entregar soluções de tecnologia que realmente resolvem problemas do setor de óleo e gás.

### O que fazemos

**Desenvolvemos software.** Ponto.

Se uma empresa de petróleo ou seus fornecedores precisam de um sistema, uma aplicação, uma integração, uma automação – a VORA entrega.

### Nossas competências

| Categoria | Tecnologias e Habilidades |
|-----------|---------------------------|
| **Backend** | Python, Node.js, FastAPI, Django, REST APIs, GraphQL |
| **Frontend** | React, Next.js, Vue.js, HTML/CSS, Tailwind |
| **Mobile** | React Native, Flutter (em desenvolvimento) |
| **Banco de Dados** | PostgreSQL, MongoDB, MySQL, Redis, InfluxDB |
| **Cloud** | AWS (certificação em andamento), Azure, Google Cloud |
| **DevOps** | Docker, Kubernetes, GitHub Actions, Terraform |
| **Data & IA** | Pandas, Streamlit, TensorFlow, Scikit-learn |
| **Automação** | RPA, workflows, integração entre sistemas |

### O que nos move

> "Resolver problemas reais com software. Sem firulas. Sem overengineering. Código que funciona e entrega valor."
