# 🚀 VORA

**Tecnologia para o setor de óleo e gás em Angola**

---

## 👋 Sobre Nós

**VORA** é uma startup angolana de desenvolvimento de software focada em soluções de dados para o setor de petróleo e gás.

Estamos construindo ferramentas que ajudam empresas a:
- 📊 Visualizar dados operacionais em tempo real
- 🔮 Prever falhas em equipamentos (manutenção preditiva)
- ☁️ Migrar e gerenciar dados na nuvem
