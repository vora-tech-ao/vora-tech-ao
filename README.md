## Sobre a VORA

A **VORA** é uma startup angolana de desenvolvimento de software especializada em soluções de dados para a indústria de óleo e gás. Nosso nome significa **"voraz"** – uma referência direta à nossa abordagem de consumir dados complexos e transformá-los em inteligência acionável.

### O que nos move

> Democratizar o acesso a dados de alta performance para empresas de petróleo e gás em Angola e na África Austral.

### Nossos Valores

| Valor | O que significa |
|-------|-----------------|
| **Agilidade** | Entregamos rápido, iteramos constantemente |
| **Segurança** | Dados críticos exigem proteção de nível militar |
| **Conteúdo Local** | Empresa angolana, talento angolano, soluções globais |
| **Inovação Contínua** | O que funcionou ontem pode não funcionar amanhã |
